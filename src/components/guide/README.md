# Guide previews

Each preview mimics a real screen. If you change that screen's layout or labels, update the matching preview and its callouts.

| Preview key | Screen it mimics |
| --- | --- |
| `materialsList` | Materials page, stock on hand list |
| `productRecipe` | Products page, add product form and recipe cost summary |
| `purchaseReceive` | Purchases page, receive purchase order dialog |
| `planMaterials` | Bookings page, planned materials dialog |
| `completeJob` | Bookings page, complete job dialog and material quantities |
| `reverseCompletion` | Bookings page, correct completed job dialog |
| `inventoryLowStock` | Materials page, low stock list |
| `payRun` | Pay runs page, generate and row actions across draft and finalized stages |
